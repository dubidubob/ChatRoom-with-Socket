# 02_ChatServer

WinSock2 non-blocking + `select` 기반 채팅 서버와 콘솔 클라이언트.
로그인, 방 생성/입장/퇴장, 방 채팅, 귓속말, 재접속 시 놓친 메시지 재전송.

## 스레드 구조

| 스레드 | 소유 상태 |
|---|---|
| Network (1) | 소켓, 패킷 조립기, 연결별 송신 버퍼 |
| Manager (1) | 유저 목록, 방 목록 |
| Room (방마다 1) | 방 멤버, 최근 메시지 128개 |

각 상태는 소유 스레드만 수정하고, 다른 스레드는 큐로 요청합니다. 잠금은 큐와 `OutboundQueue`에만 있습니다.

## 구현 포인트
- **ConnectionId**: SOCKET 값은 닫힌 뒤 재사용되므로 내부에서는 증가하는 64비트 ID를 쓴다. 늦게 도착한 송신이 새 접속으로 가지 않는다.
- **송신은 Network 스레드만**: Manager/Room은 직렬화된 불변 바이트만 넘긴다. 브로드캐스트는 바이트를 공유하고 부분 송신은 연결별 offset으로 이어 보낸다.
- **백프레셔**: 연결당 256KiB, 전체 4MiB를 넘으면 해당 연결 종료.
- **PacketAssembler**: TCP 분할/병합 처리, 타입별 길이·bool·NUL·목록 개수 검증. 잘못된 패킷은 그 연결만 끊는다.
- **입장 판정**: 정원 확인과 추가를 Room 이벤트 하나에서 처리하고 Manager는 결과로 확정.
- **종료 순서**: 입력 차단 → Manager/Room 종료 → 송신 drain(최대 2초) → 소켓 정리 → WSACleanup.

## 한계
- select + 10ms 폴링 → IOCP로 전환 필요
- 방마다 스레드 → 방을 strand로 바꾸고 스레드 풀에서 실행
- 구조체 memcpy 전송 → 가변 길이 직렬화

## 실행
`ChatServer.sln`에서 ChatServer 실행 후 ChatClient를 여러 개 실행. 서버는 `127.0.0.1:8080`.

| 명령 | |
|---|---|
| `/create <이름>` | 방 생성 후 입장 |
| `/join <번호>` | 방 입장 |
| `/roomlist`, `/userlist` | 목록 |
| `/whisper <이름> <메시지>` | 귓속말 |
| `/quit` | 방 나가기 (로비에서는 종료) |
